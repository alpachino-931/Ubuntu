## 📖 О проекте
Этот репозиторий содержит результаты выполнения практических работ по настройке виртуального сервера Ubuntu Server 24.04. 
Работа разделена на два этапа: базовая диагностика системы и создание рабочего Python-сервиса. Все действия выполнялись строго через терминал (командную строку).

---

## 📂 Структура проекта
Структура папок создана для удобного разделения кода, документации и резервных копий:

```text
ai_service/ (или ai_server/)
├── app/               # Скрипты и код программы (Python)
├── docs/              # Текстовые файлы, отчеты и заметки
├── logs/              # Журналы работы программ и ошибок
├── backup/            # Резервные копии файлов
├── reports/           # Файлы с результатами диагностики
├── .venv/             # Виртуальное окружение Python (скрыто, не грузится в Git)
├── .gitignore         # Список файлов, которые Git должен игнорировать
└── README.md          # Описание проекта (этот файл)
