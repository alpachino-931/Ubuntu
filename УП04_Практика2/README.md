## 📌 Что это за проект?
Это учебный проект, в котором я настраивал виртуальный сервер на Ubuntu, проверял сеть, создавал структуру папок и написал простой веб-сервер на Python. Сервер отвечает на запросы по адресу `127.0.0.1:8765`.

---

## 📂 Структура проекта
```text
ai_service/
├── app/               # Код программы
│   └── server.py      # Наш HTTP-сервер на Python
├── docs/              # Документация и отчеты
│   ├── about.txt      # Описание проекта
│   ├── network.txt    # Параметры сети (IP, шлюз, DNS)
│   ├── passport.txt   # Паспорт сервера (ОС, ядро, память)
│   ├── packages.txt   # Версии установленных программ
│   └── protocol.md    # Протокол испытаний сервиса
├── logs/              # Журналы работы
│   └── server.log     # Лог фонового запуска сервера
├── backup/            # Резервные копии
│   └── network_backup.txt
├── .venv/             # Виртуальное окружение Python (скрыто)
├── .gitignore         # Исключения для Git (чтобы не грузить .venv)
└── README.md          # Этот файл
